# 功能说明

## 实时系统观察

大黄狗定期采集 CPU、内存、磁盘读写、网络收发和进程资源占用，并展示近期趋势、健康度及资源占用较高的应用。

## 异常识别

- 识别持续的 CPU 或内存高负载
- 通过滚动 Median/MAD 基线发现磁盘和网络异常
- 观察应用进程组的内存增长
- 使用恢复迟滞和告警冷却减少重复提醒

## 应用与进程

进程按应用聚合展示，可展开查看成员进程、父 PID 和独立资源占用。应用使用记录区分前台与后台时间，并保留会话和运行时长。

## 本地诊断

“电脑为什么卡”使用本地规则给出解释。看门报告还会展示数字签名、路径风险与常见开机启动项，但不会把“未验证”直接判定为恶意程序。
