# 大黄狗

**一只住在 Windows 里的 AI 看门狗。**

大黄狗持续观察电脑的 CPU、内存、磁盘、网络和进程状态，在系统压力异常时给出可解释的提醒，同时坚持本地优先与安全确认。

- [功能说明](/features)：了解监控、诊断和应用使用记录
- [隐私与安全](/privacy)：了解数据保存和敏感操作边界
- [开发指南](/development)：了解项目结构与常用命令

> [!NOTE]
